# Odin Recipes 🍳

## Descripción del Proyecto
Este es el primer proyecto práctico del bloque de Fundamentos de HTML en **The Odin Project**. Consiste en un sitio web de recetas básico creado desde cero, estructurado de manera interna para conectar una página principal con múltiples páginas de recetas individuales a través de enlaces.

El objetivo principal es consolidar los conceptos fundamentales de la estructura web antes de avanzar hacia los estilos visuales.

## Habilidades Demostradas
Al finalizar este proyecto, habré demostrado un dominio práctico en las siguientes competencias de desarrollo web:

* **Estructura semántica de HTML:** Uso correcto de encabezados (`<h1>` a `<h6>`), párrafos (`<p>`), texto enfatizado (`<strong>`, `<em>`) y saltos de línea.
* **Listas en HTML:** Organización de ingredientes y pasos utilizando listas ordenadas (`<ol>`) y no ordenadas (`<ul>`).
* **Enlaces y Navegación:** Creación de rutas de archivos relativas para conectar la página principal (`index.html`) con las recetas dentro del directorio del proyecto.
* **Uso de Imágenes:** Incorporación y visualización correcta de archivos de imagen locales y externos mediante la etiqueta `<img>`.
* **Control de versiones con Git y GitHub:** Inicialización, clonación, creación de confirmaciones (*commits*) y gestión de repositorios remotos mediante la terminal.
